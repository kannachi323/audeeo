# Website design requirements

Preserve the current navbar’s visual design. Keep the landing page compact, with almost no scrolling on a desktop.

Use plain factual descriptions of the application. No slogans, promotional headlines, rhetorical contrasts, or invented benefits. No rotating text, scroll-driven scenes, decorative gradients, floating shapes, counters, testimonial sections, repeated calls to action, numbered feature cards, or entrance animations. Do not add sections just to fill space.

Show the app prominently. Prefer a genuine screenshot or the owner’s demo recording. Label interface fixtures as previews; never present them as live inference. No autoplay. Keep native video controls and respect reduced motion.

Present BYOK and the optional managed Audeeo service accurately. Do not imply signup is necessary for BYOK or that provider usage is free. Do not claim an installer is available before a verified release exists.
