# Three Little Pigs demo assets

Original Audeeo demonstration assets: narration, English adaptation, and
storybook artwork prepared for this project. These are bundled illustrative
media, not a live inference pipeline or current performance benchmark.

`render-video.sh` requires FFmpeg and Python with Pillow. Set
`AUDEEO_VIDEO_PYTHON` when Pillow is installed in a non-default Python runtime.
